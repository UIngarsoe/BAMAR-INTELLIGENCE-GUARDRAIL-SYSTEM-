သင်ပေးထားတဲ့ report ထဲမှာ အဓိကဖြစ်စဉ်တွေက—

Case A — သာကေတ

ကိုးတန်းကျောင်းသားတစ်ဦးကို လမ်းပေါ်မှာ စက်ဘီးကို ကန်လှဲပြီး ဖမ်းဆီးရန် ကြိုးပမ်းခဲ့ကြောင်း၊ ကျောင်းသားက ထွက်ပြေးလွတ်မြောက်ခဲ့ကြောင်း report က ဆိုသည်။

Case B — မင်္ဂလာတောင်ညွန့်

လမ်းသွားလမ်းလာ လူငယ် ၆–၇ ဦးခန့်ကို ရဲကား ၂ စီးဖြင့် ဖမ်းဆီးသွားကြောင်း report က ဆိုသည်။

Case C — လှိုင်

ဖေဖော်ဝါရီ ၇၊ ၂၀၂၆

အသက် ၂၅ နှစ်အရွယ် လူငယ်တစ်ဦးကို အိမ်အထိ သွားရောက်ဖမ်းဆီးခဲ့ကြောင်း report က ဆိုသည်။

Case D — မန္တလေး

စက်တင်ဘာ ၁၊ ၂၀၂၆

မဲနှိုက်ခိုင်းခြင်း၊ လမ်းပေါ်ဖမ်းဆီးခြင်း၊ ဧည့်စာရင်းစစ်ဆေးခြင်းကို အကြောင်းပြု၍ အိမ်အတွင်းအထိ ဖမ်းဆီးခြင်းများ တိုးမြှင့်လုပ်ဆောင်နေကြောင်း report က ဆိုသည်။

အဆင့်	အဓိပ္ပါယ်

Judgment	သက်သေအပေါ် အခြေခံပြီး ယုံကြည်မှုအဆင့် သတ်မှတ်ခြင်း

⚖️ ၄။ CLAIM SIZE ≤ EVIDENCE SIZE

ဒီနေ့ရဲ့ Blackboard Rule #1:

\]

📐 ၅။ Mathematical Intelligence

ကျောင်းသားတွေကို ဒီ formula ပေးမယ်—

\[
\text{Trend Rate}
=
\frac{\text{Events in Period 2}-\text{Events in Period 1}}
{\text{Events in Period 1}}
\]

ဒါပေမဲ့ ဒီ formula ကိုသုံးဖို့ Period 1 နဲ့ Period 2 ရဲ့ comparable event counts လိုပါတယ်။

ဒီ report ထဲမှာတော့—

အရင်လက စုစုပေါင်း ဘယ်နှစ်မှု?

reporting bias ဘယ်လောက်?

Claim ကို Evidence နဲ့အရွယ်ညှိတာပါ။

🟡 ၁၀။ Sentinel Preliminary Judgment

ပေးထားတဲ့ report ကို အခုရှိတဲ့အချက်အလက်အတိုင်းသာ calibrate လုပ်မယ်ဆိုရင်—

Level 1

Specific incidents reported

🟢 Potentially assessable

Level 2

Similar detention/recruitment-related patterns may be occurring in multiple Yangon/Mandalay locations

🟡 Plausible / requires independent corroboration

Level 3

The rate of such incidents is increasing

🟡 Requires time-series data

Level 4

The principal target is lower-income youth

🟠 Insufficiently demonstrated from the listed cases alone

Level 5

The increase is specifically caused by pressure to fill a particular recruitment intake

🟠 Causal claim requiring additional evidence


---

🛡️ ၁၁။ ဒီနေ့ Sentinel Rule အသစ်

ဒီနေ့အတွက် သင်တို့ရဲ့ အရင် Rules တွေကို တစ်ကြောင်းထဲ ချိတ်မယ်—

\[
\boxed{
\text{Signal}
\rightarrow
\text{Evidence}
\rightarrow
\text{Claim Size}
\rightarrow
\text{Alternative Explanations}

\text{Uncertainty}
\rightarrow
\text{Confidence}
\rightarrow
\text{Judgment}
}
\]

ပြီးတော့—

\[
\boxed{
\text{Judgment Strength}
\leq
\text{Evidence Strength}
}
\]
